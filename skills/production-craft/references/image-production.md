# 图像制作

从当前图像用途与已定要求出发选择加工方式。不是所有任务都需要生成新图：直接用源图、裁切、明暗调整、局部编辑、延展、生成或多源合成都可能合适。判断依据是素材真实性、允许用途、质量、构图和后续编辑需要。

## 把方向落实为制作约束

按本次任务确认主体数量、身份、动作、状态、必须可见的细节；视点、透视、光向、材料、局部明暗；主体位置尺度、保护区域、安静背景、裁切延展余量和分层需要。独立图像无需人为预留文字区；服务排版的图像要使用真实文字占地。

参考只承担已知用途。质量或气氛参考不自动允许复制身份、标识和独特表达。源证据里的内容不能为了画面效果改造为另一项事实；复原、模拟和概念图保留本次任务需要的真实性区分。

## 选择能保持控制的方法

选择方法时兼顾保留什么、允许变什么和如何验收。已满足要求的区域优先保留；局部缺陷不自动触发全图重做。工具限制导致精确内容不可靠时，采用可控组合方式，或明确尚未解决的限制。

迭代聚焦实际缺陷，保留关键变量稳定，比较修改前后。值得记录的拒绝原因包括：主体或数量错误、几何和解剖问题、身份不连续、文字区不可用、透视和光不符、裁切余量不足、素材条件不满足、序列不一致。不要只以“更好看”推动无限生成。

连续人物、物件或环境需要实际比较特征、空间关系和变化，不以使用了同一提示词代替连续性检查。

## 放到实际用途里验证

孤立图像可能好看但不适合布局。服务页面时加入准确文字、图注或必要标识，在实际几何中检查主体保护、局部对比、裁切和变体。独立图像则看最终尺度、边缘和交付需要。

准确的观众文字通常保持为可控制的文本或单独排字层。生成的伪文字不能算完成准确文案。原始照片中的招牌、文档或证据文字属于源内容，其保留与修改依任务及真实性要求；不要自动擦除。

为采用的素材在项目中记录来源、生成或编辑方式、使用参考、变换、版本和相关使用条件，记录深度与任务风险相称。不记录密钥、令牌或其他秘密。交付时区分实际采用图、探索图和仍有缺陷的候选。
