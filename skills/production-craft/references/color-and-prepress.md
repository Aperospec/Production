# 色彩与印前条件

用于需要色彩转换、跨空间合成或印刷文件预检的任务。只执行当前输出需要的部分；屏幕草图不自动进入印厂流程，已有合法输出也不因本方法被无条件重转。

## 先识别颜色如何被解释

读取真实源文件的颜色模式、嵌入 profile 及相关颜色描述，区分源编码、工作空间、目标输出条件和显示设备配置。相同 RGB／CMYK 数值在不同空间可能代表不同颜色。无配置不等于一定是某种常见空间；标记冲突时追查制作记录或已知来源，不能靠“看着正常”消除未知。

**指定配置**改变既有数值的解释，适合已知编码但标记缺失或错误的情形；**转换配置**通过已知源与目标改写数值，以尽可能维持目标条件下的外观。将 CMYK 模式选项打开、改文件名或贴一个目标 ICC，不等于完成正确转换。源编码没有依据时，不宣称已恢复准确颜色；可继续不依赖该判断的工作，并保留具体限制。

需要转换时保留母版，另存目标输出。使用匹配颜色模式、方向与用途的真实 profile，确认色彩引擎支持所用转换；按任务记录源／目标、引擎及版本、再现意图和有关选项。转换后读回实际颜色描述，查看必要颜色、暗部、渐变及边缘，不能只看日志成功。色域映射可能牺牲某些颜色，数值差不等于感知色差，也不是设备测量。

母版保留的依据是后续可用性，不是强制所有图像转 RGB。已分色的 CMYK、专色、纯黑文字或任务要求保留的通道，应维护其语义；反复在空间间转换可能破坏数值与分色关系。依据见 [ICC RGB 工作流示例](https://www.color.org/ICC_white_paper_23_RGB_Workflow.pdf) 和 [指定／转换的操作区别](https://helpx.adobe.com/ca/photoshop/desktop/adjust-color/color-profiles/change-color-profile-for-documents.html)。示例软件、目标 profile 和再现意图不成为通用默认。

## 合成与软打样的边界

跨源合成先建立有依据的共同颜色解释；非线性编码中的混合与在线性光中混合可能不同。明确本次需要复现软件既有外观、进行光学合成还是采用艺术混合，再选择支持该语义的流程。alpha 表示与色彩编码是两件事，不应把 alpha 当颜色做同样的伽马变换，也不应无条件改造已有正确外观。

软打样需要实际目标条件和合适的显示／观察条件；嵌入 ICC、系统存在显示 profile 或打开预览，都不能证明显示器已经校准。校准调整设备状态，特性描述记录设备行为；有仪器、方法、状态与测量记录才报告相应验证。按 [ICC 显示校准说明](https://www.color.org/displaycalibration/) 区分文件核验、软件模拟、设备测量和实体比对；不搬用一组亮度、白点或周期作为所有任务默认。

## 依接收工艺做印前预检

从接收方或已定生产要求确认 PDF 版本／交换标准、印刷过程、承印物、目标配置及真正相关的限制。仅有“印刷用”三个字时，不自选一种通用 CMYK、出血量、分辨率或 PDF/X 版本并声称已满足印厂。可以完成可编辑源与有明确地位的预览，缺少的生产条件单独说明。不同纸张、测量条件与后加工为何需要不同目标，见 [ECI 输出条件说明](https://eci.org/doku.php_id=en_colorstandards_offset.html)；其中具体工艺建议只适用其上下文。

按文件特征和接收条件核对：

- **页面几何：** 区分 MediaBox、TrimBox、BleedBox 与 CropBox；读实际数值、旋转及内容位置。框设置存在不证明画面已延展到出血；裁切标记也不等于出血。检查保护内容与装订／加工的实际余量。
- **文字与资源：** 检查实际使用的字体、嵌入／子集与缺字、链接素材及图像资源。转曲会改变搜索、文字编辑及部分显示行为；不能为绕过一个告警就静默把全部文字转曲。
- **采样与细节：** 按最终置入几何核栅格有效 PPI、细线和小字；不统一一个门槛，不把矢量或标签值当作栅格细节证明。
- **颜色与处理：** 核对象颜色空间、输出意图与实际目标的对应；按需查透明度、叠印、专色、分色与总墨量。叠印作用于色版，不等于半透明；颜色转换或专色处理次序可能改变结果。需要分色或 RIP 预览的项目，普通 RGB 缩略图不能证明通过。

保留透明度还是扁平化由交换标准和接收链决定，不把扁平化设为通用修复。修复后重新预检并渲染，尤其对照小字、细线、叠印和重叠边缘。根据实际用途查 [PDF/X 的约束与边界](https://pdfa.org/wp-content/uploads/2017/05/PDFX-in-a-Nutshell.pdf)、[标准版本索引](https://pdfa.org/resource/iso-15930-pdfx/) 与 [叠印的技术解释](https://pdfa.org/understanding-overprint/)；概览不是标准全文或认证，后者是专业作者的解释，不是协会统一政策。

## 使验证结论与证据相等

文件能打开、指定标准合规、接收工艺适配和物理印刷质量是不同结论。OutputIntent 或合规元数据是声明，不是通过证明；普通解析器可查部分结构，但不能据此写“PDF/X 验证通过”。没有对应预检器时，如实交付已完成的结构与视觉检查及未验证范围。

验证处理链时记录实际输入、工具版本、影响输出的设置、输出和观察；只测本次用到的特征，不声称覆盖所有 PDF。相互作用可能需要组合试件进入真实流程，[GWG Output Suite 的方法](https://gwg.org/gos5/) 说明了这种测试与单独预检的区别。未运行的测试套件、未经过的 RIP、设备、纸样或认证均不写成已完成。
